# Phachara-Portfolio-kub

Personal bilingual portfolio for Phachara Changyouang.

## Local preview
Open `index.html` or serve locally with `python -m http.server 8080`.

## Vercel
Import this repository as a static site (Framework Preset: Other, Build Command: blank, Output Directory: `.`). No environment variables required.

## Privacy and deployment
Only curated public descriptions and images are included. AHA private repositories are not published. Deployment is intentionally not performed in this version.
